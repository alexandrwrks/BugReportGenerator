# BugReportGenerator

Сервис для работы с локальной ИИ-моделью `Qwen3:4b` (на 4 миллиарда параметров).
Сервис представляет собой один endpoint в котором пользователь может написать свою проблему. 
После чего модель сгенерирует ответ в Pydantic модели.
Ответ от модели идёт в потоковом режиме (`stream=True`)

## Стек технологий

- Python 3.12
- FastAPI
- Ollama
- httpx
- uvicorn
- Pydantic

## Основные возможности

- Работа с локальной моделью
- Получение подробной и структурированной информации о том как исправить проблему возникшая у пользователя

## Локальный запуск

### Требования для запуска проекта локально

- Python 3.12 и менеджер пакетов `uv`
- Ollama клиент и локальная модель. В проекте используется `qwen3:4b`

### Запуск

```shell
# Создание виртуального окружения
uv venv

# Запуск FastAPI приложения
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Запуск с помощью Docker
```shell
docker compose up -d --build

# Загрузка модели 
docker compose exec ollama ollamapull qwen3:4b
# Остановка контейнера
docker compose down

# Остановка контейнера, удаление всех данных и скачанных моделей
docker compose down -v
```

## Проверка

По адресу `http://localhost:8000/docs` можно будет открыть **Swagger UI** и проверить endpoint-ы

## Возможные проблемы
Если вы попытаетесь запустить проект локально, но у вас не будет установлена Ollama, то при запросе к endpoint-у
`/bug-reports/draft` возникнет ошибка подключения к Ollama сервису — `httpx.TimeoutException` или `ConnectionError`,
а в обработчике генерации, ошибка превратится в SSE-событие `report_error`. 
Если не будет установлена модель, то можно будет воспользоваться endpoint-ом `/ollama/pull` и загрузить модель и сохранить её в `ollama_data`.
